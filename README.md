# MOFFアプリ (Moff隊 釣果記録帳)

エリアトラウト（管理釣り場）におけるフェザーフィッシング愛好者（Moff隊）向けの釣果記録・分析Webアプリケーションです。

![MOFFアプリ](https://img.shields.io/badge/MOFFアプリ-HartDesignフェザーログ-amber)
![Platform](https://img.shields.io/badge/Platform-Web%20%2F%20Mobile-blue)

---

## 🎣 主な特徴

- **木目調＆真鍮プレートの高級感あるアングラー向けデザイン**
- **HartDesign フェザーに特化した入力UI**
  - Light Wing, Giant Wing, CRAZY, Canvas, Twinkle, Light Wing LD などのワンタップ選択
  - ルアーカラー、ウエイト、アクションパターンの記録
- **エリアトラウト魚種対応**
  - ニジマス、ブラウントラウト、ブルックトラウト、イワナ、ヤマメ、イトウ、F1、アルビノなど
- **自動写真圧縮・拡大モーダル**
  - 高画質な釣果写真を自動的に最適化してローカル保存（端末容量パンクを防止）
- **通算釣果アナリティクス**
  - 総キャッチ数、最大サイズ（Big Fish）、最多ヒットルアー、メインエリアの自動集計
- **検索・絞り込み**
  - エリア・ルアー・魚種による複合フィルタリング
- **オフライン動作 & バックアップ**
  - ブラウザのLocalStorageで完全ローカル動作
  - JSON形式での釣果データのエクスポート・インポート対応

---

## 🚀 使い方

1. `index.html` を任意のブラウザ（Chrome, Safari, Edgeなど）で開くだけで即座に使用できます。
2. スマホのホーム画面に追加してアプリ感覚で現場で利用することも可能です。

---

## 🛠️ 使用技術

- HTML5 / CSS3 (Vanilla CSS + Tailwind CSS CDN)
- JavaScript (ES6+ / LocalStorage API / Canvas API)
- FontAwesome 6 / Google Fonts (Zen Maru Gothic & Shippori Mincho)
